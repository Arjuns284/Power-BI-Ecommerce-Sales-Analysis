# E-commerce Sales & Profitability Analysis Dashboard

## Project Overview
This project focuses on analyzing retail sales data using Microsoft Power BI. The objective is to understand sales performance, profitability, product trends, and customer behaviour through interactive dashboards.

## Tools & Technologies
- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel

## Dataset
The project uses the Sample Superstore dataset containing retail sales information, including:
- Order details
- Customer information
- Product categories and sub-categories
- Sales and profit
- Discounts
- Geographical information
- Order and shipping dates

## Project Workflow

### 1. Data Import and Transformation
- Imported the Sample Superstore Excel dataset into Power BI.
- Used Power Query Editor for data inspection and transformation.
- Prepared the data for analysis.

### 2. Data Modelling
- Created a separate Calendar table.
- Established a relationship between the Orders table and Calendar table using Order Date.

### 3. DAX Calculations
Created measures to analyze:
- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Average Order Value

## Key Objectives
- Understand overall sales and profitability.
- Identify high-performing product categories.
- Analyze regional sales performance.
- Identify top-selling products and customers.
- Examine discount patterns and their relationship with profitability.
- Support data-driven business decisions.
